게임 설명
게임 방법
  1. 게임 시작 버튼을 누르고, 아이디를 입력한 후 게임을 시작한다.[cite: 3]
  2. 화면을 꾹 누르면 (마우스로 클릭하면) 강민재가 과자를 먹는다.
    * 과자를 먹는 동안 점수가 오른다.[cite: 3]
  3. 차주한이 랜덤하게 문을 열고 들어온다.
    * 차주한이 들어올 때, 강민재가 과자를 먹고 있으면 게임 아웃!
    * 과자를 들키지 않았다면, 차주한이 문을 닫고 나간다.[cite: 3]
  4. 차주한에게 들키기 전까지 게임을 진행한다.[cite: 3]
이벤트 참여방법
  1. 게임 오버 화면의 점수와 아이디가 나오게 캡처한다.[cite: 3]
  2. 해시태그와 함께 트위터에 게시글을 올린다.
    (공유하기 버튼을 누르면 바로 트위터로 이동!)[cite: 3]
  3. 구글 폼을 작성한다.[cite: 3]
  4. 참여상 윗치폼을 작성하고 배송비를 입금한다.[cite: 3]
  5. 순위 결과를 기다린다.[cite: 3]
